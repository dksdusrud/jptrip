# 구라시키·다카마쓰·오사카 1.22–1.25

세토우치 겨울 기차여행(5인 자유여행) 일정 페이지입니다.

- 날짜별 경로·시간표, 즐길거리·먹을거리·숙소 후보(별표로 고르기)
- 비용(환율 입력), 날씨·옷차림, 체크리스트

별표와 체크 표시는 보는 사람 브라우저(localStorage)에만 저장됩니다.

## GitHub Pages로 열기

1. 이 폴더를 저장소로 올립니다.
2. 저장소 **Settings → Pages**에서 Source를 `Deploy from a branch`, 브랜치 `main` / 폴더 `/ (root)`로 지정합니다.
3. 잠시 뒤 `https://<계정>.github.io/<저장소>/` 에서 열립니다.

공개 저장소의 Pages는 링크를 아는 누구나 볼 수 있습니다.
